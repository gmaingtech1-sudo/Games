# The Silent Harvest: Necrons vs Imperial Guard

A 44-second unofficial fan animation. A Guard trench line holds the Ash Wastes at night while a Necron tomb wakes up. The warriors rise, take lasgun hits and get back up, a tank shells their line, and then a pyramid ship comes down. It ends with a commissar leading the charge.

**[Watch the video](necrons-vs-guard.mp4)** (1280×720, 30 fps, stereo sound)

Every frame and sound is generated by code. There is no artwork or audio from elsewhere. To render it again you need Python 3 with Pillow and NumPy, plus ffmpeg:

```
python3 render.py            # writes necrons-vs-guard.mp4 (about a minute)
```
