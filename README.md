# Games

Small games for phones. Each one lives in its own folder.

| Game | Description |
| --- | --- |
| [Pocket Mochi](pocket-mochi/) | A virtual pet for touchscreen phones. Hatch it, feed it, pet it, wash it, and play Star Catch to earn coins for snacks and hats. |
| [Pocket Mochi for Android](pocket-mochi-android/) | The same game as an installable Android app. [Download the APK](pocket-mochi-android/dist/pocket-mochi.apk). |
| [Pet Cam](pet-cam/) | A real-looking AR dog, cat or bunny that lives in your phone's camera. Play with it with your finger: pet it, hand-feed it, wave a toy or laser for it to chase, play fetch and take photos together. |
| [Pet Cam for Android](pet-cam-android/) | The same game as an installable Android app. [Download the APK](pet-cam-android/dist/pet-cam.apk). |
